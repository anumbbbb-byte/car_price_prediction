# car_price_prediction

## Project Overview

This project focuses on predicting car prices using Machine Learning. The project includes data preprocessing, exploratory data analysis, feature selection, and model training using Linear Regression.

## Machine Learning Workflow

1. Data Loading
2. Exploratory Data Analysis (EDA)
3. Data Preprocessing
4. Feature Selection
5. Train-Test Split
6. Linear Regression Model
7. Model Evaluation

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## Model Used

**Linear Regression**

Linear Regression was used to predict car prices based on the selected features from the dataset.

## Model Performance

| Metric | Result |
|---|---:|
| R² Score | 0.83 |
| MSE | 3,634,217.50 |
| RMSE | 1,906.36 |

The model achieved an R² score of **0.83**, meaning that the model explains approximately **83% of the variation in car prices**.

The complete implementation is available in the Jupyter Notebook included in this repository.

The notebook contains the complete process from data preprocessing and feature selection to model training and evaluation.
